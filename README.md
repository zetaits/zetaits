## Selected projects

### 🖥️ [KioskClinicaPC](https://github.com/zetaits/KioskClinicaPC)

A complete kiosk system built for a real computer shop.

The desktop application automatically detects the hardware of each computer, presents it through a customer-facing touch interface, generates portable product sheets through QR codes, and can optionally connect to a central management panel for controlling multiple kiosks.

**Highlights:**

* Desktop kiosk application
* Central web administration panel
* Real-time synchronization with SignalR
* Offline fallback and local caching
* Hardware detection
* QR-based PDF generation
* Remote fleet management
* Authentication and security controls

**Stack:** `.NET 8 · WPF · Blazor · SignalR · JavaScript`

---

### ✉️ [ChronoMail Bridge](https://github.com/zetaits/ChronoMail-Bridge)

A desktop application for safely archiving historical email and migrating it from Turbify/Yahoo Small Business into Google Workspace.

It is designed for long-running migrations where reliability matters, with resumability, deduplication, persistent state, safe retries, and conservative failure handling.

**Highlights:**

* IMAP email archival
* Gmail API integration
* OAuth authentication
* Resumable migrations
* SQLite persistence
* Message deduplication
* Exponential backoff and circuit breaking
* Automated simulation and testing

**Stack:** `.NET 8 · WPF · Gmail API · MailKit · SQLite · OAuth`

---

### 🔎 [Local Business Auditor](https://github.com/zetaits/Local-Business-Auditor)

A local application for automatically auditing business websites and identifying technical and usability problems.

It crawls websites, runs browser-based checks and Lighthouse audits, collects evidence, prioritizes findings, and provides a workflow for manually reviewing the results.

**Highlights:**

* Automated website crawling
* Browser automation with Playwright
* Lighthouse performance analysis
* Responsive/mobile checks
* Background audit queue
* Screenshot evidence
* SQLite persistence
* React-based interface

**Stack:** `React · TypeScript · Fastify · Playwright · Lighthouse · SQLite`
